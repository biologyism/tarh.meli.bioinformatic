Bulk RNA-Seq Foundation
طراحی آزمایش، کنترل کیفیت، هم‌ترازی ومعادله-expression
استاد: خانم دکتر ★ (نام در منبع ناخوانسته است) ۲ جلسه · ۴ ساعت
جلسه اول — Foundation (۱ جلسه)
  • مرور transcriptome و Central dogma؛ سوال‌های RNA-seq
  • اصول طراحی آزمایش (Experimental design): تعداد replicate، اثر batch، عمق توالی
  • انتخاب‌های کتابخانه: polyA، stranded، rRNA depletion، unstranded، single-end، paired-end
  • اصول توالی Illumina؛ فرمت FASTQ و Phred quality score
  • کنترل کیفیت: FastQC و MultiQC؛ Trimming: Trimmomatic و fastp
  • آماده‌سازی محیط (Linux، conda)، است-reference (FASTA، GTF از Ensembl GENCODE)
جلسه دوم — From Aligned Reads to Expression Values (۲ ساعت)
  • مفهوم alignment و aligners bite-splice-aware (STAR، HISAT2)، ساخت genome index و اجرای alignment
  • فرمت SAM/BAB و samtools
  • QC از alignment: mapping rate، Qualimap، RSeQC
  • Quantification: HTSeq-count و featureCounts
  • روش‌های pseudo-alignment: Salmon، kallisto، tximport، ساخت count matrix
  • واحدها: CPM، RPKM/FPKM، TPM و raw count؛ DEG و چرا استفاده می‌شود

Finding the Most Important Genes with DEG Analysis
تحلیل تفاضلی الجينات با DESeq2، edgeR، limma-voom
استاد: ★ (نام استاد در منبع ناخوانسته است) ۳ جلسه · ۶ ساعت
۳ جلسه — منطق آماری و تحلیل انحصاری
  • منطق آماری: توزیع Negative Binomial، dispersion، size factor
  • Exploratory analysis: PCA، VST/rlog، heatmap، فاصله بین نمونه‌ها، شناسایی outlier
  • طراحی design matrix و contrast (افزودن batch به عنوان covariate)
  • اجرا DESeq2 و edgeR و limma-voom
  • آزمون‌های آماری: Wald و LRT، تصحیح چندتگانه Multiple testing correction (FDR، روش Benjamini-Hochberg)
  • LFC shrinkage و انتخاب threshold
  • مصورسازی: Volcano plot، heatmap، MA plot

From Gene List to Pathway
تغذیه کارکردی، ORA، GSEA،STRING و miniproject
استاد: دکتر مرعشی (استنتاج از 조선 منبع) ۴ جلسه + mini-project + جلسه پنجم پروژه العمق · ۱۰ ساعت
۴ جلسه — از لیست جین به مسیر/pathway
  • چرا Functional enrichment؟ آشنایی با MSigDB، GO، KEGG، Reactome
  • Over-Representation Analysis (ORA) و انتخاب background gene set
  • Gene Set Enrichment Analysis (GSEA) و ranked list (fgsea، clusterProfiler)
  • ابزارهای وب: g:Profiler، Enrichr
